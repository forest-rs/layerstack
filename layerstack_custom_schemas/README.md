# layerstack_custom_schemas

A schema library of its own, built as a downstream crate builds one: the
`lab` (laboratory instruments) and `observatory` (telescopes) schemas of
`layerstack_conformance/fixtures/schema_compiler` as Rust views that
`layerstack_schemagen` generates, compiled against `layerstack_schemas`'
public API alone.

- `lab` is generated by `build.rs` with `CompiledSchema::rust_module` and
  included from `OUT_DIR`, built on its `plugInfo.json`, whose `Kinds` it
  registers (`lab::register_kinds`).
- `observatory` builds on OpenUSD's `Xformable`, so generating it needs OpenUSD's
  schema sources; it is checked in at `src/generated/observatory.rs`:

  ```sh
  cargo run -p layerstack_schemagen -- compile \
    layerstack_conformance/fixtures/schema_compiler/observatory/schema.usda \
    --openusd-source <OpenUSD> --rust layerstack_custom_schemas/src/generated/observatory.rs
  ```

  `tests/generated.rs` checks it is current when `LAYERSTACK_OPENUSD_SOURCE`
  names an OpenUSD 26.08 checkout.

`tests/views.rs` reads and authors every kind of generated view on a USDA
stage; `layerstack_conformance`'s `schema_compiler` test checks that the
modules' registration agrees with OpenUSD's registry.
